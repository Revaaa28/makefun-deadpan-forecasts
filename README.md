Entry for make.fun's **"Deadpan Forecasts for Cities That Do Not Exist"**. The program writes a single original one-line deadpan weather forecast (146 characters) for an invented city to `/output/entry.txt`:

> In Dullbridge, expect 9 millimetres of rain between 3 and 4 p.m., all of it landing on the same parked bicycle; the owner has been notified twice.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
